## Critical Notes

### `api.getThreadInfo(threadID)` — pure async
```js
// ✅ CORRECT
const info = await api.getThreadInfo(threadID);
// info.threadName, info.participantIDs, info.nicknames

// ❌ WRONG — does not accept a callback
api.getThreadInfo(threadID, (err, info) => { ... });
```

### `api.sendTypingIndicator(sendTyping, threadID, callback)` — boolean first
```js
// ✅ Start typing
await api.sendTypingIndicator(true, threadID);

// ✅ Stop typing
await api.sendTypingIndicator(false, threadID);

// ❌ WRONG — threadID is not the first argument
api.sendTypingIndicator(threadID, callback);
```

### `api.nickname(nickname, threadID, participantID, callback)` — NOT setNickname
```js
// ✅ CORRECT
await api.nickname("Hades", threadID, userID);

// ❌ WRONG — function does not exist
api.setNickname(...);
```

### `api.gcname(newName, threadID, callback)` — supports callback + Promise
```js
// ✅ Both work
await api.gcname("My Group", threadID);
api.gcname("My Group", threadID, (err) => { ... });
```

### `api.gcmember(action, userIDs, threadID, callback)`
```js
// action: "add" | "remove"
await api.gcmember("add",    ["uid1", "uid2"], threadID);
await api.gcmember("remove", ["uid1"],         threadID);
```

### `api.sendMessage(msg, threadID, callback)`
```js
// msg can be string or object: { body, attachment, mentions, ... }
await api.sendMessage("Hello!", threadID);
api.sendMessage({ body: "Hi", attachment: stream }, threadID, (err, info) => { ... });
```
